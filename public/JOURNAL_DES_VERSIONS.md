# Journal des versions

Les versions 0.x ont été testées en jeu par Dan seul, de 2026-11-03 à 2026-11-09 ; la première version publique les réunit.

## 1.2.0 (en préparation)

- **Une fenêtre pour signaler une erreur** : cliquez sur le nouveau bouton Azeroth_FR de la minicarte, visez le texte en cause (objet, sort, bouton, menu, texte de fenêtre), cochez ce qui ne va pas, copiez et collez sur le Discord. Clic droit sur le bouton : les options.
- **La difficulté « Ascended » s'appelle « transcendé »** partout : « Raid transcendé », « en mode transcendé », « Transcendé : Hakkar ».
- **Étiquettes des objets en français** : classes (« Guerrier »), couleurs (« Vert »), créatures et apparences (« Loup », « Drake noir », « Élémentaire d'eau »), lieux et modes (« Temple d'Ahn'Qiraj héroïque », « Donjon : Le Nexus », « Raid : Le sanctum Obsidien - 10 joueurs »). Environ 7 000 lignes de plus en français.

## 1.1.1 (2026-11-10)

- **Le Discord Azeroth_FR** est indiqué partout : bouton « Rejoindre le Discord » dans l'installateur, adresse dans le panneau d'options. C'est là que sont annoncées les versions et que l'on signale les erreurs.

## 1.1.0 (2026-11-09)

- **L'installateur se met à jour tout seul** : à son lancement, il regarde sur GitHub s'il existe une version plus récente, la télécharge, vérifie le fichier et l'installe. Vous gardez le même installateur d'une version à l'autre. Sans connexion, il installe la version qu'il contient.
- **En jeu, « une nouvelle version est disponible »** : quand un joueur de votre guilde ou de votre groupe a une version plus récente d'Azeroth_FR, un message vous le dit, et le panneau d'options aussi.

## 1.0.1 (2026-11-09)

- **Carte du monde** : le nom de la zone survolée (avec ses niveaux) et les listes « Continent » et « Zone » sont en français.
- **Soutenir le créateur** : un encart dans l'installateur et dans le panneau d'options, pour ceux qui veulent offrir un café.
- Correction des textes : Conquest of Azeroth a 21 classes.

## 1.0.0 (2026-11-09) : première version publique

- **Installateur guidé**, étape par étape : Bienvenue, Dossier du jeu, Installation, C'est prêt.
  - Il trouve le jeu tout seul ; sinon il le cherche sur vos disques, ou vous le choisissez. Un dossier voisin du bon est corrigé.
  - Si le jeu est ouvert, il attend que vous le fermiez, puis installe.
  - En cas d'erreur, il dit quoi faire.
  - À la fin, il indique la suite : lancer le jeu, vérifier le bouton AddOns, `/azfr`.
- Code publié sous licence MIT (les textes du jeu ne sont pas couverts).

## 0.9.6 (2026-11-09)

- **Installateur** pour Windows et Linux : il trouve le dossier du jeu, installe, met à jour ou désinstalle en un clic, sans internet.
- **Panneau d'options dans le jeu** (Interface, AddOns, Azeroth_FR, ou `/azfr`) : couper la traduction, ou seulement les bulles des PNJ, les messages au centre de l'écran, les plaques de nom.
- Le logo d'Azeroth_FR dans le panneau et l'installateur.

## 0.9.5 (2026-11-09)

- **Tous les sorts des 21 classes vérifiés.** Avec les classes d'origine du jeu, 6 925 capacités, talents et passifs ont été contrôlés un à un, puis relus.
- **Noms cohérents.** Un sort, une spécialisation ou un nom cité porte le même nom partout : grimoire, talents, descriptions, fenêtres de CoA.
- **Texte détaillé des sorts** (touche MAJ) en français, avec « Maintenez MAJ pour plus d'informations ».
- **Écran de sélection** : « Courrier non lu ».
- **Hauts faits** : ceux repassés en anglais sont retraduits.
- **Typographie** : accents sur les capitales (« Éclat », « Âme »).
